=== COMO TESTAR O PROJETO EQUIPCONTROL ===

Olá, Professor! 
Para que o projeto fique mais leve para envio, a pasta "node_modules" foi removida. 
Para rodar o aplicativo e avaliar nosso trabalho, por favor siga os passos abaixo:

1. Abra o terminal (ou Prompt de Comando/PowerShell) dentro desta pasta do projeto (Equip-control).

2. Instale as dependências executando o comando:
   npm install

3. Após a conclusão da instalação, inicie o servidor do Expo rodando:
   npm start

4. O terminal exibirá um QR Code. Você pode escaneá-lo com o aplicativo "Expo Go" no seu celular, ou pressionar a tecla "w" no terminal para visualizar no navegador (caso prefira testar a versão web).

Telas e Funcionalidades desenvolvidas (Fase 2 - Formulário, AsyncStorage e Navegação):
1. Formulário (EquipmentFormScreen):
   - Abertura via navegação pelo botão flutuante (+) na lista.
   - Campos: Nome (obrigatório), Categoria (com chips interativos) e Responsável Inicial.
   - Validação com alerta quando o nome não for preenchido.
   - Salvamento e persistência no AsyncStorage com retorno automático à lista.

2. Lista (EquipmentListScreen):
   - Carregamento inicial e revalidação dinâmica do AsyncStorage ao receber foco (useFocusEffect).
   - Indicadores visuais de status (badges coloridos, contadores em tempo real de Total, Em Uso e Disponíveis).
   - Navegação para a tela de detalhes ao clicar em qualquer cartão.

3. Detalhes (EquipmentDetailScreen):
   - Exibição completa das informações do equipamento.
   - Botão para marcar/desmarcar o status ("Marcar como Em Uso" / "Marcar como Disponível").
   - Persistência imediata no AsyncStorage e retorno à lista atualizada.

Agradecemos a avaliação!
