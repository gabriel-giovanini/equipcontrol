=== COMO TESTAR O PROJETO EQUIPCONTROL ===

Olá, Professor! 
Para que o projeto fique mais leve para envio, a pasta "node_modules" foi removida. 
Para rodar o aplicativo e avaliar nosso trabalho, por favor siga os passos abaixo:

1. Abra o terminal (ou Prompt de Comando/PowerShell) dentro desta pasta do projeto (Equipcontrol).

2. Instale as dependências executando o comando:
   npm install

3. Após a conclusão da instalação, inicie o servidor do Expo rodando:
   npm start

4. O terminal exibirá um QR Code. Você pode escaneá-lo com o aplicativo "Expo Go" no seu celular.

Telas e Funcionalidades desenvolvidas (Fase 3 - SQLite e CRUD Completo):
1. Banco de Dados SQLite (src/database/database.js e App.js):
   - Inicialização automática da tabela "equipments" ao abrir o aplicativo.
   - Consultas SQL parametrizadas (INSERT, SELECT, UPDATE, DELETE) com tratamento de erros.

2. Formulário de Cadastro e Edição (EquipmentFormScreen):
   - Abertura pelo botão flutuante (+) na lista para novo cadastro ou pelo botão "Editar" nos detalhes.
   - Validação completa de campos obrigatórios (nome com mínimo de 3 caracteres, categoria, formato e validade de datas DD/MM/AAAA, responsável obrigatório quando "Em uso").
   - Persistência direta no SQLite (insertEquipment e updateEquipment).

3. Lista e Filtros com SQL WHERE (EquipmentListScreen):
   - Carregamento direto do SQLite ao focar na tela (useFocusEffect) e suporte a pull-to-refresh.
   - Filtros nos cartões superiores (Total, Em Uso e Disponíveis) executando consultas reais no SQLite com cláusula WHERE (SELECT * FROM equipments WHERE status = ?).
   - Estados de carregamento, tratamento de erros e mensagens de lista vazia contextualizadas.

4. Detalhes e Exclusão com Confirmação (EquipmentDetailScreen):
   - Exibição completa das informações sincronizadas com o SQLite.
   - Alteração rápida de status de empréstimo/devolução ("Marcar como Em Uso" / "Registrar Devolução").
   - Botão "Editar Dados" (reutilizando o formulário preenchido) e botão "Excluir" com diálogo de confirmação (Alert.alert) antes da remoção no banco.

Agradecemos a avaliação!
